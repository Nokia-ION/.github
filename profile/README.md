# Nokia-ION GitHub organisation

## What is in this organisation?

This GitHub organisation is the home of the stewarded open source projects we create in relation to the Nokia IP network products.

Nokia steward is an open-source software steward as defined in the European Union
[Cyber Resilience Act Article 3(14)](https://eur-lex.europa.eu/legal-content/EN/TXT/HTML/?uri=OJ:L_202402847#art_3).
